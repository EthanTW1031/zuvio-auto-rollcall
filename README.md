# Zuvio 自動點名助手

給同學使用：

1. 第一次使用先雙擊 `第一次使用-安裝套件.bat`
2. 上課時雙擊 `開始點名.bat`，會打開點名視窗
3. 在視窗裡登入 → 點選課程 → 按「開始自動點名」
4. 偵測到點名開放後會自動送出，成功時視窗會跳到最前面並發出提示音

想用原本的文字介面，可以改雙擊 `開始點名-文字版.bat`。

帳號密碼只會在當次執行中使用，不會寫進檔案。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `zuvio_gui.py` | 視窗版介面（Tkinter，Python 內建，不用另外安裝） |
| `開始點名.bat` → `zuvio_gui_launcher.ps1` | 視窗版入口與啟動器：找 Python、缺套件時自動安裝，再開視窗 |
| `開始點名-文字版.bat` → `zuvio_launcher.ps1` → `zuvio_interactive.py` | 文字版入口、啟動器與介面 |
| `zuvio_rollcall.py` | 共用核心：登入、讀課程、偵測與送出點名 |
